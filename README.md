## 1.製作動機

我目前有兼職擔任國小一年級英文老師。

小朋友剛開始學習英文單字時，如果只是一直看單字或背中文意思，
容易覺得無聊，也不一定能直接把英文單字和實際物品產生連結。

因此我想設計一個「英文單字 × 圖片」的翻牌配對遊戲，
讓學生透過遊戲練習看到英文單字時，直接聯想到對應的圖片。

另外，每堂課需要複習的單字不一定相同，因此網站不是使用固定題目，
而是讓老師依照當天的課程內容，自行選擇或輸入想複習的單字。

## 2.目標使用者
主要使用者為：
-	英文老師在課堂上當作複習活動使用（主要是我上課可以用）
-	國小低年級學生
-	剛開始學習基礎英文單字的學生
介面需要簡單、字體清楚、按鈕大，讓小學生也能直覺操作。

##  3.遊戲玩法

1. 老師先選擇或輸入本次想複習的英文單字。
2. 系統檢查這些單字是否存在於內建單字資料庫。
3. 系統自動產生「英文單字卡」與「圖片卡」並隨機洗牌。
4. 遊戲開始時所有卡片都是背面。
5. 玩家一次翻開兩張卡片。
6. 如果是正確的「英文單字＋圖片」配對，兩張卡片保持翻開。
7. 如果配對錯誤，顯示 `Try again!`，卡片稍後重新蓋回去。
8. 所有卡片成功配對後，顯示 `Great job!`。
9. 可以使用同一組單字重新洗牌再玩一次。

## 5.內建單字

第一版的單字主要來自目前班上學生正在學習的課本內容。

目前支援例如：

`ant` 🐜 · `bee` 🐝 · `cat` 🐱 · `duck` 🦆 · `egg` 🥚  
`fish` 🐟 · `hat` 🎩 · `kite` 🪁 · `lion` 🦁 · `milk` 🥛  
`octopus` 🐙 · `pig` 🐷 · `rock` 🪨 · `sun` ☀️ · `van` 🚐  
`wind` 💨 · `box` 📦 · `yoyo` 🪀

之後若要增加單字，只需要在 JavaScript 的單字資料庫中加入新的
「英文單字 → 圖片／圖示」配對。

##  6.視覺設計

- 以可愛、簡單、直覺的風格為主
- 使用大尺寸卡片與按鈕，方便電子白板操作
- 英文字體大且清楚，方便低年級學生辨識
- 使用翻牌動畫與配對提示提供明確的視覺回饋

## 7.Vibe Coding 修改過程

這個作品不是一次完成，而是先和 ChatGPT 討論需求、建立規格，
再依照實際使用情境持續修改。

### 第一次規劃
原本只設計固定幾組英文單字與圖片進行翻牌配對。

### 修改 1：改成老師可以自行選擇單字
因為每堂英文課需要複習的內容不同，
所以後來改成由老師輸入或選擇本堂課的單字，
再由系統自動建立遊戲。

### 修改 2：加入 Random Words
考量在電子白板上逐一輸入單字較不方便，因此加入 Random Words 功能，
可以自動隨機選出數個單字，讓老師在臨時想進行複習活動時，也能快速開始遊戲

### 修改 3：移除計分功能
原本規格中設計配對成功可以獲得分數，
但後來考慮一年級學生可能會因為分數產生比較或挫折感，
因此最後移除計分，改成以 `Great match!`、`Great job!`
等正向提示作為回饋。

### 修改 4：加入重新遊玩功能
完成一局後可以直接使用相同單字重新洗牌，
不需要老師再次輸入單字，
比較適合實際在電子白板上重複進行課堂活動。

## 10.完成成果

最後完成了一個可以實際在英文課堂上使用的單字複習工具。

老師可以依照當天的教學進度選擇想練習的英文單字，
系統會自動產生對應的圖片翻牌遊戲。

學生需要記住卡片位置，並找出「英文單字＋圖片」的正確配對，
讓學生在遊戲過程中反覆接觸英文單字。

完成一局後可以直接重新洗牌再玩一次，
不需要重新輸入單字，因此也適合搭配電子白板進行課堂活動。
