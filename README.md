## 1.製作動機

我目前有兼職擔任國小一年級英文老師。

小朋友剛開始學習英文單字時，如果只是一直看單字或背中文意思，
容易覺得無聊，也不一定能直接把英文單字和實際物品產生連結。

因此我想設計一個「英文單字 × 圖片」的翻牌配對遊戲，
讓學生透過遊戲練習看到英文單字時，直接聯想到對應的圖片。

另外，每堂課需要複習的單字不一定相同，因此網站不是使用固定題目，
而是讓老師依照當天的課程內容，自行選擇或輸入想複習的單字。

## 2.目標使用者
主要使用者為：
-	英文老師在課堂上當作複習活動使用（主要是我上課可以用）
-	國小低年級學生
-	剛開始學習基礎英文單字的學生
介面需要簡單、字體清楚、按鈕大，讓小學生也能直覺操作。

##  3.遊戲玩法

1. 老師先選擇或輸入本次想複習的英文單字。
2. 系統檢查這些單字是否存在於內建單字資料庫。
3. 系統自動產生「英文單字卡」與「圖片卡」並隨機洗牌。
4. 遊戲開始時所有卡片都是背面。
5. 玩家一次翻開兩張卡片。
6. 如果是正確的「英文單字＋圖片」配對，兩張卡片保持翻開。
7. 如果配對錯誤，顯示 `Try again!`，卡片稍後重新蓋回去。
8. 所有卡片成功配對後，顯示 `Great job!`。
9. 可以使用同一組單字重新洗牌再玩一次。

## 5.內建單字

第一版的單字主要來自目前班上學生正在學習的課本內容。

目前支援例如：

`ant` 🐜 · `bee` 🐝 · `cat` 🐱 · `duck` 🦆 · `egg` 🥚  
`fish` 🐟 · `hat` 🎩 · `kite` 🪁 · `lion` 🦁 · `milk` 🥛  
`octopus` 🐙 · `pig` 🐷 · `rock` 🪨 · `sun` ☀️ · `van` 🚐  
`wind` 💨 · `box` 📦 · `yoyo` 🪀

之後若要增加單字，只需要在 JavaScript 的單字資料庫中加入新的
「英文單字 → 圖片／圖示」配對。

##  6.視覺設計

- 以可愛、簡單、直覺的風格為主
- 使用大尺寸卡片與按鈕，方便電子白板操作
- 英文字體大且清楚，方便低年級學生辨識
- 使用翻牌動畫與配對提示提供明確的視覺回饋

## 7.Vibe Coding 修改過程

這個作品不是一次完成，而是先和 ChatGPT 討論需求、建立規格，
再依照實際使用情境持續修改。

### 第一次規劃
原本只設計固定幾組英文單字與圖片進行翻牌配對。

### 修改 1：改成老師可以自行選擇單字
因為每堂英文課需要複習的內容不同，
所以後來改成由老師輸入或選擇本堂課的單字，
再由系統自動建立遊戲。

### 修改 2：加入 Random Words
考量在電子白板上逐一輸入單字較不方便，因此加入 Random Words 功能，
可以自動隨機選出數個單字，讓老師在臨時想進行複習活動時，也能快速開始遊戲

### 修改 3：移除計分功能
原本規格中設計配對成功可以獲得分數，
但後來考慮一年級學生可能會因為分數產生比較或挫折感，
因此最後移除計分，改成以 `Great match!`、`Great job!`
等正向提示作為回饋。

### 修改 4：加入重新遊玩功能
完成一局後可以直接使用相同單字重新洗牌，
不需要老師再次輸入單字，
比較適合實際在電子白板上重複進行課堂活動。

## 11. 更新紀錄（2026/11/17）

隨著英文課程的進度，學生已經從最初的 A–Z 基礎單字，逐漸學習到動物、數字、動作及 5W1H 疑問詞。

因此，這次依照實際課堂的需求，對原本的遊戲進行功能擴充，保留原有的翻牌配對玩法，讓學生可以使用熟悉的遊戲方式複習更多英文內容。

### 更新 1：擴充內建單字資料庫

原本的單字主要以 A–Z 基礎單字為主，這次增加了更多課堂上學過的內容，包括：

- **A–Z 基礎單字**：原本的字母單字及補充單字
- **Animals 動物**：dog、bird、cow、horse、rabbit 等
- **Actions 動作**：dance、sing、read、write、drive、jump 等
- **Numbers 數字**：one～ten
- **5W1H 疑問詞**：who、what、where、when、why、how

讓網站可以隨著教學進度持續擴充，不需要每次都重新製作新的遊戲。

### 更新 2：新增單字分類功能

為了讓老師能夠更快速地選擇當天要複習的內容，新增單字分類功能。

老師可以直接選擇特定的主題，再使用 Random Words 隨機抽取單字，減少每次上課重新輸入的時間。

### 更新 3：新增混合模式（All）

除了依照主題分類練習，也新增了混合模式 All。

選擇混合模式後，系統會從所有已收錄的單字中隨機抽題，讓學生可以同時複習不同單元的內容。

這個功能主要是考量學生學過的單字越來越多，希望不只是複習當週的新單字，也能持續接觸之前學過的內容。

### 更新 4：加入 5W1H 疑問詞配對

最近在課堂上開始教 Who、What、Where、When、Why、How，但發現部分學生對於不同疑問詞的意思還不太熟悉。

因此，希望利用學生原本就喜歡的翻牌配對遊戲，幫助他們加強記憶。

由於 5W1H 比較抽象，不容易直接用圖片表達，所以改成搭配中文意思與簡單圖示，例如：

- Who → 誰
- What → 什麼
- Where → 哪裡
- When → 何時
- Why → 為什麼
- How → 如何

讓遊戲不再只限於具體物品的圖片配對，也可以用來練習基礎英文疑問詞。


### 更新後的成果

這次更新後，網站從原本以 A–Z 基礎單字為主的翻牌遊戲，擴充成可以依照不同英文課程主題進行複習的工具。

目前除了單字與圖片配對，也加入了部分英文與中文意思的配對，讓遊戲能應用在更多教學內容上。

未來也可以隨著學生的學習進度繼續增加單字與題型，讓這個網站成為長期使用的英文課堂輔助工具。
